SVU DEVELOPERS WEBSITE - QUICK START

1. Make sure Node.js LTS is installed on Windows.
2. Double-click START-WEBSITE.bat.
3. The launcher starts the website at http://localhost:3000.

This build removes the 360-degree tour and adds editorial scroll storytelling, a scroll progress line, parallax hero motion, reveal-on-scroll sections, and compact floating phone/WhatsApp icons linked to +91 83518 35836.

The build environment could not download npm dependencies, so node_modules is not bundled in this ZIP. The launcher automatically runs npm install if dependencies are missing, so you do not need to type the command manually. An internet connection is required for first-time setup. Source syntax and ZIP integrity are checked; a full Next.js build and browser interaction test could not be run here.
